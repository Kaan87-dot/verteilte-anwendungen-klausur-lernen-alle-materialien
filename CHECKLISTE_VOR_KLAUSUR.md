# 🎨 Zeichnungen üben

## ✅ Kannst du diese Diagramme zeichnen?

### Communication Patterns:
- [ ] Request/Response Pattern
```
Client → Request → Server
Client ← Response ← Server
```

- [ ] Pub/Sub Pattern
```
Publisher → Topic → Subscribers (mehrere)
```

- [ ] Message Queue Pattern
```
Producer → Queue → Consumer
```

### Architekturen:
- [ ] Three-Tier Architecture
```
Presentation Tier (Frontend)
     ↕ HTTP
Business Logic Tier (Backend)
     ↕ SQL
Data Tier (Database)
```

- [ ] Client-Server-Modell
```
Client ⇄ Server
```

### OSI-Modell:
- [ ] 7 Schichten von oben nach unten
```
7. Application
6. Presentation
5. Session
4. Transport
3. Network
2. Data Link
1. Physical
```
