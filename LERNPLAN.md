## 🗓️ Detaillierter Lernplan

### Phase 1: Fokus auf die wichtigsten Themen (60% der Punkte!)

#### Tag 1-2: HTTP Grundlagen & Methoden (3-4 Stunden)
**Warum wichtig?** HTTP = viele Punkte in der Klausur!

**Was lernen:**
- [ ] HTTP Methoden verstehen (GET, POST, PUT, DELETE, PATCH)
- [ ] Status Codes kennen (200, 201, 400, 404, 500, etc.)
- [ ] REST Principles verstehen
- [ ] Request/Response Struktur
- [ ] HTTP Headers (Content-Type, Authorization, etc.)

**Lernmaterial:**
- Lies: [WICHTIGE_THEMEN.md - HTTP Sektion](WICHTIGE_THEMEN.md#http)
- Übe: [CODE_BEISPIELE.md - HTTP Beispiele](CODE_BEISPIELE.md#http)

**Lernziel:**
✅ Du kannst HTTP Code-Lücken ausfüllen
✅ Du weißt, welche Methode für welche Operation
